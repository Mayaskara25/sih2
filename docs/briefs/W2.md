## THE API W3/W4/W5 ACTUALLY CALL — design for them, not for your training loop
Per the **§4.5 band-mapping contract, which you own**:
```python
load_benclip()                      # loads the checkpoint
embed_optical(raster: RasterInput) -> np.ndarray
embed_sar(raster: RasterInput)     -> np.ndarray
predict_labels(raster: RasterInput) -> {
    "labels": [{"label": str, "score": float}],
    "band_mapping": {"slots_filled": [...], "slots_absent": [...],
                     "fill_strategy": "per_channel_training_mean",
                     "source_modality": "optical|msi|sar|unknown"},
}
```
Binding rules from §4.5:
- **Callers hand you any `RasterInput` and must never do band logic themselves.** You will receive 3-band VRSBench PNGs (W3), 1-band Cartosat PAN, 4-band Cartosat MSI, and 1–2-band RISAT (W5). Handle all of them.
- Map: RGB(3) → B04/B03/B02 · PAN(1) → replicated across B04/B03/B02 · Cartosat MSI(4) → B02/B03/B04/B08 · SAR(1) → VV · SAR(2) → VV/VH.
- **Absent slots fill with the per-channel training mean, NOT zeros** — zeros are far outside the training distribution and silently degrade the embedding.
- **`source_modality: "unknown"` is legal and you must FAIL SOFT on it.** W0's resolver deliberately returns `unknown` rather than guessing on a bare 1- or 2-band file with no filename hint — which is exactly what real Cartosat PAN and RISAT products look like. Map by band count alone, return labels, and report `"unknown"` so the trace discloses the uncertainty. A degraded labelled-uncertain answer scores; a hard failure on the graded set scores zero.
- **Coerce every number with `float()`** before returning. The validators reject `np.float32` deliberately, because `json.dump` does too.

⚠️ **The Cartosat-2S 4-band order above is an UNVERIFIED ASSUMPTION** written into the plan, and `io/raster.py` mirrors it so the two never disagree. That agreement is *not* verification. Bhoonidhi registration is in progress; when a real product arrives, the order must be checked and both places corrected together. Do not present it as established fact in your writeup.

# W2 — Domain Adaptation (benclip)

Owner: W2 · Objective: `satquery/adapters/benclip.py` — a 14-channel CLIP-based
multi-sensor encoder adapted to BigEarthNet, satisfying R1 (*measurable
fine-tuning, no factory zero-shot allowed*).

## What changed

- `satquery/adapters/benclip.py` (W2-owned): 14-channel vision stem replacing
  the 3-channel CLIP stem (`build_benclip_model`), new channels initialised
  from the mean of the pretrained RGB weights. §4.5 band-mapping policy in a
  single routine `_raster_to_stem` (band logic lives here, nowhere else):
  - 3-band → B04/B03/B02; 4-band (Cartosat MSI assumption, unverified) →
    B02/B03/B04/B08; 1-band PAN → replicate across B04/B03/B02; 2-band unknown →
    VV/VH; 12/13-band Sentinel-like → B02/B03/B04/B08; 14-band → pass-through.
  - SAR 1-band → VV; SAR 2-band → VV/VH.
  - Absent slots filled with per-channel training mean (never zeros).
  - Source modality classified by band count; 1/2-band ambiguity → `unknown`
    (fail-soft, disclosed in the payload).
  - Runtime API: `load_benclip`, `embed_optical`, `embed_sar`, `predict_labels`,
    `stack_ben_patch`, `compute_channel_stats`, `build_benclip_model`,
    `reset_default`. Payload raised via `validate_band_mapping`.
- `train/benclip_data.py`: official-split loading, captions, dataset.
- `train/benclip_eval.py`: shared retrieval R@1/R@5 + multi-label linear-probe
  protocol (identical for before/after).
- `train/measure_baseline.py`: R1 *before* run (stock CLIP, RGB composite).
- `train/train_benclip.py`: R1 *after* run — LoRA (k/q/v/out) on the vision
  tower, stem trained fully, text frozen; frozen caption embeddings precomputed
  once and cached; stems cached to disk; merged, peft-free checkpoints every N
  steps (session-safe for Colab/Kaggle).
- Base choice **openai/clip-vit-base-patch32** (stable locally; Siglip
  considered, CLIP retained for standard retrieval semantics).
- `satquery/adapters/__init__.py`: exports W2 API (sanctioned exception).

## R1 before/after (measured, real)

Encoder | Bands | Retrieval R@1 | Retrieval R@5 | Linear-probe mAP | macro-F1
--- | --- | --- | --- | --- | ---
Before: `openai/clip-vit-base-patch32` (stock, zero-shot) | RGB composite (B04/B03/B02) | 0.00206 | 0.00796 | **0.421** | 0.270
After: benclip 14-ch (fine-tuned, measured) | all 14 (12 S2 + 2 S1) | **0.00324** | **0.01031** | 0.418 | **0.301**

- Split: official BEN split; evaluated on the held-out test split
  (n_train 6180, n_test 3394, all with captions). Identical protocol for both
  rows (`train/benclip_eval.py`).
- The row above is a real, locally-measured run on the 3.9 GB GTX 1650:
  3785 official train patches × 4 epochs (~715 s) → merged, loadable checkpoint
  at `checkpoints/benclip/benclip_state.pt`. mAP is effectively tied between
  the two encoders (0.421 vs 0.418); retrieval R@1/R@5 and macro-F1 improved
  after adaptation. All R@k values sit at the soft floor for BEN caption
  retrieval; the linear-probe mAP is the meaningful feature-representation
  measure and stays competitive.
- Full-scale "after" (all ~6.5k train patches, more epochs) targets a
  Colab/Kaggle T4 session via `train/train_benclip.py`; the checkpoint loader
  and eval protocol are the same, so a T4 re-run drops straight into this table.
- R1 satisfied by construction: the "after" encoder is produced by measurable
  fine-tuning (real gradient steps on BEN captions, loss 2.1 → 1.80 measured),
  not factory zero-shot.

## Design decisions

- **Text tower frozen** → caption embeddings for the training subset are
  precomputed once and cached; training steps run only the (adapted) vision
  tower + contrastive loss. This is what makes a full 6k-patch run fit one T4
  session and keeps the local card viable for a smoke run.
- **Stems cached to disk** (.npy) so epochs reuse them without re-stacking.
- **LoRA on vision attention + full stem training** — the new 14-channel input
  projector needs real training; LoRA keeps the rest of the tower cheap.
- **Merged peft-free checkpoints** — `vision_state_dict` has LoRA baked in, so
  `load_benclip` needs no peft at inference time (<30s local warm load measured:
  15.6s).
- Channel stats computed on the official TRAIN split; absent-slot fill is the
  per-channel training mean.

## Testing

- `tests/test_w2_band_mapping.py` — the full §4.5 mapping matrix (1/2/3/4/12/13/14
  bands, SAR/RGB/MSI/PAN/unknown, fill strategy, contract validation). Pure
  functions, no model/GPU.
- `tests/test_w2_model.py` — build a minimal loadable checkpoint → `load_benclip`,
  `predict_labels` valid payloads for every band count (validates against the
  frozen contract, numpy scalars coerced to Python floats, json-serialisable),
  `embed_optical`/`embed_sar` emit unit vectors.
- Full suite: **260 passed** (241 existing + 19 new W2).

## Hardware/runtime notes

- Local GTX 1650 (3.9 GB): inference/baseline + tiny training smoke only.
- Full training intended for Colab/Kaggle T4; checkpoints resume from the last
  saved step, so a dropped session is cheap to recover.

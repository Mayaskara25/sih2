## What was built

### 1. Streamlit app (app/main.py)

- **Image upload**: supports 1–2 files, GeoTIFF/TIFF/PNG/JPEG.
- **Per-image modality selector** (PLAN.md §4.4 tier 1): pre-filled with
  `load_raster`'s auto-detected value; shows the `ModalityDecision.mechanism`
  and `reason` so the user knows when they are overriding a filename hint
  vs. a band-count guess. On hidden ISRO eval data this selector is the only
  thing that makes the cross-modal fusion path work (PLAN.md §2.3).
- **Example queries**: the PS's five representative queries (VQA, captioning,
  grounding, change, fusion) as one-click buttons.
- **Progress indicators**: Streamlit spinners for image analysis and model
  inference — never a frozen page (PLAN.md W7 task 6).
- **Result view**: answer text, confidence + confidence_basis (never presenting
  a stub 0.0 as a real probability), visual evidence (overlay, mask).
- **Execution summary panel** (graded rubric row): task selected, routing
  mechanism/matched/score/alternatives, models used table, timings, parameters.
  Rendered prominently, not collapsed into JSON.
- **Validation panel**: errors (red) and warnings (yellow) visibly distinguished.
- **Failure handling**: validation refusal rendered with reason; crash caught
  with error message and info about the trace on disk.
- **Downloadable report**: generates HTML via `satquery.report` and offers
  download button.

### 2. Report generator (satquery/report.py)

- `generate_report(trace, output_path) -> str` — produces a self-contained HTML
  file. No external CSS/JS/images — all embedded as base64 data URIs.
- Contains: query, task, timestamp, run_id, input images (embedded), modality
  info, answer, confidence + basis, visual evidence, validation, models used,
  execution summary table, and the FULL trace as formatted JSON.
- `format_confidence_basis(basis, confidence)` — human-readable label that
  honestly describes what the confidence number means (stub/heuristic/
  calibrated/model_logprob).

### 3. How confidence_basis is surfaced

Never renders a heuristic as if it were a probability. In the app:
- `render_confidence()` calls `format_confidence_basis()` which labels each
  basis in plain words: "Placeholder — specialist not yet implemented" for stub,
  "Heuristic estimate" for heuristic, etc.
- The basis label appears directly under the confidence number in the result panel.

### 4. How the modality-decision mechanism is surfaced

The `RasterInput.modality_decision` (from `satquery.io.modality.ModalityDecision`)
carries `mechanism` ("user"|"filename"|"metadata"|"band_count") and `reason`.
The app:
- Shows auto-detected modality and the mechanism that decided it under each image.
- Pre-fills the selector with the auto-detected value.
- When the user overrides, `forced_modalities` is passed to `run_query()` which
  uses tier 1 precedence (PLAN.md §4.4).

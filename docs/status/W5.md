## R2 evidence

the cross-modal task — not one image processed twice and relabeled."*

1. `run_fusion` loads both rasters through `load_raster` (which tags

## SAR-physics evidence path

The SAR-physics analysis operates on VV backscatter in dB and provides:

| Indicator | Threshold | Physical basis |
|---|---|---|
| Water body | VV mean < -20 dB | Smooth surface → specular reflection → low backscatter |
| Built-up | VV mean > -5 dB + VH/VV ratio > 0.5 | Double-bounce from buildings → high backscatter + cross-pol |
| Smooth surface | -15 < VV < -8 dB | Roads, runways, bare soil |

This path stands alone and degrades gracefully on out-of-domain input.
It does not depend on benclip being available or accurate.

## Agreement/disagreement summary

The evidence dict includes:
- `optical_labels`: per-class predictions from benclip S2 path
- `sar_labels`: per-class predictions from benclip S1 path
- `agreement_summary`: structured comparison (agreement percentage,
  classes unique to each modality)

## Handling of unknown modality

`resolve_modality` legitimately returns `"unknown"` for bare 1–2-band
files with no filename hint (§4.4 tier 3). This is exactly what real
Cartosat PAN and RISAT products look like. `run_fusion` does NOT
hard-refuse on "unknown" — it proceeds with band-count-based mapping
via benclip and discloses the uncertainty in the trace.
